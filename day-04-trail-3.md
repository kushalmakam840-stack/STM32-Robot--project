## Objective
Control the speed of an N20 DC gear motor using a push button and PWM generated by the STM32F401RBT6.

## Hardware Used
- STM32F401RBT6 (Raayan Mini board)
- N20 6V 200RPM DC gear motor with encoder
- TB6612FNG motor driver
- Push button
- External motor power supply
- Breadboard and jumper wires

## PWM Configuration
- Timer: TIM2
- PWM Channel: Channel 1
- PWM output pin: PA0
- Prescaler (PSC): 83
- Auto-reload value (ARR): 99
- PWM frequency: Approximately 1.9 kHz

## Button Configuration
- GPIO input configured with internal pull-up
- Button pressed: GPIO_PIN_RESET (LOW)
- Button released: GPIO_PIN_SET (HIGH)

## Implementation
Implemented button-controlled PWM duty-cycle switching using a counter and odd/even logic.

- Odd button press count: 30% duty cycle
- Even button press count: 50% duty cycle
- Button release detection prevents repeated counting while the button is held.
- Motor direction is controlled through the TB6612FNG driver using GPIO outputs.

## Undertanding
- Reading a push button using STM32 HAL GPIO functions.
- Understanding active-low button logic with an internal pull-up.
- Using a counter and modulo operator (`count % 2`) to alternate between two states.
- Changing PWM duty cycle at runtime with `__HAL_TIM_SET_COMPARE()`.
- Preventing repeated button counts by detecting button release.
- Combining GPIO and timer PWM to control a DC motor.
