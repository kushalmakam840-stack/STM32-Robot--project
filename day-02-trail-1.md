## Hardware Used

1.STM32F401RBT6 (Raayan Mini board)

2.TB6612FNG motor driver

3.N20 6V 200RPM DC gear motor

4.External motor power supply

## Software Used

1.STM32CubeIDE

2.STM32 HAL library

3.Embedded C

## Work Completed

1.Interfaced the STM32 microcontroller with the TB6612FNG motor driver.

2.Tested the motor using control signals generated by the STM32.

3.Practiced peripheral configuration and embedded C development using STM32 HAL.

## Understanding
Understood the basic process of controlling a DC motor through a motor driver using an STM32 microcontroller.
